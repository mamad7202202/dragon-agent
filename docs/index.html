why dragon

Built around memory

Most agents forget you the second a session ends. Dragon doesn't.

◈Hybrid memory

Semantic fact store, procedural MEMORY.md and resumable session logs — recalled every turn by relevance × importance × recency.

◇Bring your own key

Preset one-liners for Google AI Studio, OpenRouter, OpenAI, Anthropic, Groq, DeepSeek, Ollama and LM Studio. Keys never leave your machine.

◆Native speed

Pure Rust, single static binary per platform. Millisecond cold starts, streaming everything.

▣Real tool use

Read and write files, grep with regex, walk directories, run shell commands behind an explicit opt-in gate.

▤Two faces, one core

The TUI and the desktop app share one core crate — same memory, same providers, same sessions.

◉Private by default

No accounts, no telemetry. Config and transcripts live in your user directory and nowhere else.
