modes

Three ways to talk to it.

Switch per session — chat to think out loud, plan before touching files, agent when you mean it.

chat

Pure conversation. No tools, no file access — fastest and cheapest.

plan

Read-only research: files, grep, web. Ends with a concrete numbered plan — nothing changes on disk.

agent

The full toolkit: read, write, edit, delete, shell, fetch. Actions that change the world ask first.

memory

Memory is the product.

Most agents forget you the moment a tab closes. Dragon remembers — precisely, and cheaply.

semanticfacts.json
Discrete facts recalled every turn by relevance × importance × recency. No vector database — scoring runs locally, offline, in microseconds.
proceduralMEMORY.md
Standing instructions in plain markdown, always loaded into the prompt.
episodicsessions/*.jsonl
Every conversation kept as an append-only transcript — resumable any time.
compactionlong sessions
Old turns fold into an LLM summary once history passes a threshold; recent turns stay verbatim.
score = relevance × (0.55 + 0.45·importance) × (0.7 + 0.3·recency) × scope_boost

why dragon

Built around remembering.

From day one — plus everything you'd expect from a serious tool.

◆Permission gate

Writes, deletes and shell commands pause for approval. “Always allow” remembers your choice, and an independent explainer says what an action does before you decide.

▣Sessions everywhere

Every conversation is a resumable JSONL transcript. Continue last week's task in the GUI or the CLI — history, mode and memories come back with it.

▤BYOK presets

Google AI Studio, OpenRouter, OpenAI, Anthropic, Groq, DeepSeek, Ollama, LM Studio — one-liner setup, keys never leave your machine.

◉Native speed

Pure Rust, hand-rolled SSE streaming, one binary per platform. Millisecond cold starts — no Node, no Electron.

◇Private by default

Config, memory and transcripts live in your user directory. Nothing is sent anywhere except the provider you chose.

◈Ember-lit TUI

A ratatui interface with streaming responses and live tool activity — built for long nights in the terminal.

providers

Your keys. Your models.

Eight built-in presets, plus any OpenAI-compatible endpoint. Mix providers freely — each keeps its own key and model list.
